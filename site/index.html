Installateur MeshCore

Flashez une carte nRF52 en Companion ou Répéteur, directement depuis le navigateur, par USB.

Navigateur non compatible. L’installation par USB utilise Web Serial : ouvrez cette page avec Chrome ou Edge sur ordinateur (Windows, macOS, Linux). Vous pouvez quand même télécharger le fichier .uf2 ci-dessous.

1 Votre carte

« Détecter » interroge la carte par USB. Si elle n’est pas reconnue, appuyez deux fois sur RESET : un lecteur USB apparaît, cliquez sur « Lire INFO_UF2.TXT » et choisissez ce fichier sur le lecteur.

Ou choisissez-la dans la liste :

3 Installation

  1. Branchez la carte avec un câble USB data.
  2. Cliquez sur Installer et choisissez le port série de la carte.
  3. La carte redémarre seule en mode bootloader, puis le firmware est écrit (≈ 1 min).

4 Connecter à l’application

      
    
        
  1. Installez l’application MeshCore : iPhone,
          Android ou version web.
    2. 
        
  2. Activez le Bluetooth et ajoutez l’appareil. Code PIN par défaut : 123456 (ou celui affiché sur l’écran de la carte).
    3. 
        
  3. Dans les paramètres radio, choisissez le preset de votre région. En France : EU/UK (Narrow), 869.618 MHz, SF8, BW62.5, CR8.
    4. 
        
  4. Donnez un nom à votre nœud et réglez la puissance TX.
    5. 
      

      
⚠ Module avec amplificateur (30 dBm / 1 W) : la puissance réelle est ~8–10 dB au-dessus du réglage. En Europe sur 869,4–869,65 MHz la limite est 500 mW (27 dBm ERP) : réglez environ 17 dBm dans l’application.
